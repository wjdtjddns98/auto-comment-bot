개인정보처리방침

Nutti(이하 "운영자")는 소셜 미디어 키워드 모니터링 및 사람 승인형 답글 도구(이하 "서비스")를 운영하며, 관련 법령과 Meta 플랫폼 정책을 준수합니다. 본 방침은 서비스가 Threads API 를 통해 취급하는 정보에 적용됩니다.

1. 수집·이용하는 정보

  • 운영 계정 정보: 운영자가 직접 소유·운영하는 Threads 계정의 액세스 토큰과 프로필 식별 정보(username). 토큰은 암호화하여 저장합니다.
  • 공개 게시물 정보: 운영자가 설정한 키워드에 매칭된 공개 Threads 게시물의 본문·작성자명·링크·게시 시각.
  • 서비스는 일반 이용자의 회원가입을 받지 않으며, 비공개 게시물·메시지·연락처 등 공개 범위를 넘는 정보를 수집하지 않습니다.

2. 이용 목적

  • 키워드 기반 공개 게시물 모니터링(소셜 리스닝)
  • 운영자(사람)가 게시물을 검토하고 명시적으로 승인한 경우에 한해 운영 계정으로 답글을 게시 — 자동 게시 기능은 없습니다.

3. 보관 및 파기

  • 액세스 토큰: 계정 연동 해제 또는 삭제 요청 시 지체 없이 파기합니다.
  • 수집한 공개 게시물 정보: 모니터링 목적 달성 후 또는 삭제 요청 시 파기합니다.

4. 제3자 제공

수집한 정보를 제3자에게 판매·제공하지 않습니다. 법령에 따른 요청이 있는 경우는 예외로 합니다.

5. 데이터 삭제 요청

Threads 계정 연동 해제 및 데이터 삭제 절차는 데이터 삭제 안내를 참고하시거나, 아래 연락처로 요청하실 수 있습니다. 요청 접수 후 7일 이내에 처리합니다.
