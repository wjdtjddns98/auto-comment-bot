데이터 삭제 안내 (Data Deletion Instructions)

Nutti 의 키워드 모니터링 서비스와 연동된 Threads 계정 데이터의 삭제 절차입니다.

연동 해제 (앱 권한 회수)

  1. Threads 앱/웹 → 설정 → 계정 → 웹사이트 권한 으로 이동합니다.
  2. 연결된 앱 목록에서 본 서비스를 선택하고 연동 해제합니다.
  3. 해제 즉시 서비스는 해당 계정의 API 접근 권한을 잃습니다.

저장 데이터 삭제 요청

  1. 아래 이메일로 삭제를 요청해 주세요: {{연락처 이메일}}
  2. 요청 접수 후 7일 이내에 해당 계정의 액세스 토큰과 관련 저장 데이터를 파기하고, 완료 사실을 회신해 드립니다.

기타 문의는 개인정보처리방침을 참고해 주세요.
